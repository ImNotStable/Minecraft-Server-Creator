# msc-renderer

A headless renderer that turns a region into images so the AI can check how a build looks.

**Phase:** Post-MVP  
**Status:** Planning. No code yet.

## Scope

- Top-down, isometric and first-person camera views.
- Uses the resource pack, including generated textures.
- Image size budgets to keep token cost down.

## Depends on

- `msc-core` for region data and textures.

## Stack

Java 21, Gradle Kotlin DSL.
