# msc-docs

The home for plans, the spec, the tool catalogue and decision records for Minecraft Server Creator.

**Phase:** MVP  
**Status:** Planning. No code yet.

## Scope

- The master plan (`docs/plan.md`), kept in sync with the shared plan doc.
- The tool catalogue: every MCP tool's name, inputs, output shape and token budget.
- The core-to-agent protocol spec (the reference that `msc-protocol` implements).
- Architecture decision records in `docs/adr/`.

## Depends on

- None. Every other module links here.

## Stack

Java 21, Gradle Kotlin DSL.
