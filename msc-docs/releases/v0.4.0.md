## Highlights

This release passed the Hollowroot release-gate playtest: an original six-trial Minestom game built with MSC and played to the end by `player_test`.

### Test player

- **Richer `player_test`**: on request it reports the inventory (hotbar, backpack, armour, open menus with item names, `item_model` and lore), the HUD (boss bars, sidebar, action bar, title, tab list, pack state), and it can `interact` with entities and use merchant trades. Menu titles are readable, and the player sends one move packet per tick, so Paper no longer kicks it on interact or attack.

### Building and checking the world

- **`world_summary path="A B"`** says whether a player can walk and jump from A to B, or names the wall, gap, fence, door or lava that stops them. **`diff=FILE`** lists what changed since a `structure_save` snapshot.
- **`build_batch`** gains a `helix` step (spiral stairs) and `repeat=N step=DX,DY,DZ` on every step.
- **`api_class`** lists constants inherited from interfaces and superclasses.

### Fewer tools, faster loop

- **30 tools down to 26**: the 8 texture tools are folded into `texture`, `texture_view`, `model_create` and `pack`. `texture` draws, generates or recolors, and can animate in the same call. New sword, pickaxe and food shapes.
- **`dev_cycle` edits in about 7.6 s instead of 19 s**: it builds only the deployable jar, runs tests while the server restarts, keeps the server when the jar is unchanged, and prints a time per phase. Minestom deploys a thin jar plus `libs/`.
- **Generated tool docs**: the tool tables in `tools.md` are generated from code, and the build fails when they are stale.

### Under the hood

- **`msc-agent-common`**: the Paper, Fabric and Minestom agents share one implementation of the operations, undo history and core connection (about a quarter less agent code).
- **Minestom end to end in CI**: a real Minestom server is driven through the installed core over MCP, from scaffold to `player_test` to stop.
- **Bench**: Minestom tasks that need no EULA, and the game-scale **Sky Sprint** task.

### Hollowroot fixes

- `minestom-game` keeps progress across reconnects (stable offline UUIDs).
- Templates commit the resource pack sources (`.msc/pack/`).
- Retexturing a `minecraft:` texture no longer replaces vanilla's model.
- `player_test use x,y,z` says when the block is out of reach.
- `server_command` shows the exception line on failure.
- `installMsc` keeps the Linux and macOS launcher executable.

### Install

Download `msc-core-0.4.0.zip` and follow the wiki's Installation page, or install the plugin. Java 25 must be on the PATH.
