## Highlights

Everything from scratch. MSC now gives the AI general primitives, guidance and quality reviews, and never a prefab, preset or stock asset: every build, interior, landscape, texture, model, menu look, sound, message and line of code is the agent's own ([ADR 0106](../docs/adr/0106-from-scratch.md)). Around that rule this release adds a standard library for every platform, real land and generated worlds, a build loop that judges its own work (reviews, tours, play-tests), proxy networks, plugin installs, profiling, crash triage that points at the code, and export to Docker or Pterodactyl. A last audit exercised every tool on real servers ([ADR 0107](../docs/adr/0107-core-tools-audit-2026-11.md)).

### Breaking changes

- **Removed presets.** `build_batch` no longer has `roof`, `tree`, `forest`, `feature`, `furnish`, `boat`, `harbor` or `pier`, nor `flora style=` or `terrain style=` ([ADR 0101](../docs/adr/0101-no-prefab-boats-or-harbours.md), [ADR 0103](../docs/adr/0103-no-content-presets.md)); `terrain noise=fbm|ridged|terraced|waves` replaces `style=` and `river` needs `bed=`. `texture kind=` (stock shapes and patterns) is gone: draw with `rows=`, or recolour your own with `copy=` ([ADR 0106](../docs/adr/0106-from-scratch.md)). Each removed step or option is refused with a pointer to what to do instead.
- **msc-stdlib 3.0.0** ships plumbing, not looks: no `Gui.Theme` presets, `Gui.confirm`, stock sounds, styled feedback or canned UI text. Projects scaffolded with 2.x keep the version they pinned.
- **Bare templates** ([ADR 0073](../docs/adr/0073-bare-templates.md)): the game templates are gone; every template is a Gradle build, standard plugins, metadata and an empty entry point.
- **Protocol 3** ([ADR 0092](../docs/adr/0092-sealed-frames.md)): every frame after the handshake is sealed with an HMAC. Run `server_setup` once in each existing server folder to replace the agent jar.

### New

- **Standard library on every platform** ([ADR 0066](../docs/adr/0066-standard-library.md), 0085, 0086, 0104): databases (SQLite, MySQL, MariaDB, PostgreSQL, MongoDB, Redis), migrations, caches, menus, items, sidebars, particles, commands, NPCs and dialogue, minigames, loot, permissions and data packs, for Paper, Minestom, Fabric, NeoForge, Forge, Velocity and BungeeCord/Waterfall, with code graphs so an agent finds what it needs cheaply.
- **Land** ([ADR 0075](../docs/adr/0075-land-and-generated-worlds.md), [ADR 0080](../docs/adr/0080-shaping-steps.md)): `world_create` adds generated worlds (the game's terrains and biomes); `build_batch` gains `terrain`, `path`, `scatter`, `clump=`, and the shaping brushes `smooth`, `erode`, `blend`, `paint`, `river`, `tunnel` and `cave`.
- **Hand-placed detail** ([ADR 0077](../docs/adr/0077-hand-placed-detail.md), [ADR 0082](../docs/adr/0082-things-in-a-build.md), [ADR 0093](../docs/adr/0093-usable-doors-windows-and-fence-lines.md)): blocks join as a player's would, a block that leaves facing, half, axis and the like to the default is refused, `trim`, `decorate`, `weather` and `light` work on what is built, and signs, banners, heads, books, containers, entities, frames, stands, biomes and pictures (`image`) are steps.
- **Reviews and tours** ([ADR 0068](../docs/adr/0068-quality-bar-for-any-agent.md), 0078, 0084, 0094 to 0099): `world_summary review=true` judges builds and land (detail, flat walls, speckle, roofs, bare bases, empty and dark rooms, doors, ladders, leaves, hulls, dark streets, each building of a town) and says `verdict: NOT DONE` until it passes; `world_tour` shows a build at eye height; `msc_status` and `dev_cycle` list reviews still failing.
- **Play-testing** ([ADR 0087](../docs/adr/0087-test-player-plays-the-game.md)): `player_test` clicks menus and chat buttons, finds NPCs by name and lints the pack the server served.
- **Every resource pack file** ([ADR 0081](../docs/adr/0081-every-pack-asset-type.md)): `pack_asset` writes fonts and HUD glyphs, sounds, lang, models, item definitions, blockstates, equipment, atlases, shaders and more, checked against Minecraft 26.3; `msc_status guide=pack` documents each.
- **Plugins and mods** ([ADR 0057](../docs/adr/0057-plugins-from-modrinth-hangar-spigot.md)): `plugins search=` and `install=` from Modrinth, Hangar and SpigotMC, with required dependencies and checksums.
- **Networks** ([ADR 0088](../docs/adr/0088-proxy-networks.md)): `server_setup servers=lobby,game` runs Paper backends behind Velocity or Waterfall, with `@backend` commands and play-tests through the proxy; Geyser on a proxy.
- **Folia world tools** ([ADR 0100](../docs/adr/0100-folia-world-tools.md)): world, build and player tools run on Folia's region threads.
- **Crash triage points at the code** ([ADR 0089](../docs/adr/0089-crash-sources.md)), **`server_profile`** ([ADR 0090](../docs/adr/0090-server-profile.md)) and **`server_export`** to Docker Compose or Pterodactyl eggs for every platform ([ADR 0091](../docs/adr/0091-server-export.md), [ADR 0102](../docs/adr/0102-more-pterodactyl-eggs.md)).
- **NMS in Paper projects** ([ADR 0059](../docs/adr/0059-nms-for-paper-plugins.md)) and `plugin.yml` generated at build time ([ADR 0060](../docs/adr/0060-plugin-yml-from-resource-factory.md)).
- **Backups before every edit** ([ADR 0069](../docs/adr/0069-backup-before-every-edit.md)).

### Fixed in the final audit

`pack_asset` no longer doubles a sound or glyph on a repeated call; unknown items in chests, frames and stands are refused instead of vanishing; ground cover is reviewed as land; `server_profile` gives no advice from a handful of samples; the review's mix advice passes its own bar; refusals name the refused block's own example and close names despite a typo; msc-core writes nothing to stderr on a normal run.

### For developers

- Gitea is the working home; GitHub carries `main`, releases and packages, and both wikis match ([ADR 0063](../docs/adr/0063-wiki-on-gitea.md)). Renovate replaces Dependabot ([ADR 0064](../docs/adr/0064-renovate-on-gitea.md)).
- `FromScratchTest` fails CI on a new preset step, a preset-picking option or a stdlib constant outside its reviewed allowlist.

### Install

Download `msc-core-0.7.0.zip` and follow the wiki's Installation page, or install the plugin. Java 25 must be on the PATH.
