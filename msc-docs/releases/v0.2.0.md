## Highlights

Playtest release: the AI can now play what it builds, and build bigger things in fewer calls.

### New tools

- **`player_test`**: a headless test player joins the dev server and runs actions (walk, sprint, jump, look, use, attack, chat, commands). Each action reports chat, titles, damage, deaths, respawns and server corrections, and the player stays joined between calls.
- **`build_batch`**: many build steps in one call with one undo id: fills, rooms, cylinders, rings, discs, spheres, domes, lines, terrain bands and stamped structures with repeat, rotate and face. Weighted block mixes (`grass_block:78,moss_block:10`), every block name checked before anything is placed, and `dryRun` to check and count only.
- **`msc_workspace`**: switch every tool to another project folder without restarting the MCP server.
- **`world_entities`**: list entities in a region with type, name, position, health and tags; checks wave spawns, NPCs and holograms without a player.
- **`server_wait`**: wait for a log or chat line (regex) instead of polling, for example `until="Wave 3"`.

### New template

- **`paper-game`**: a Paper minigame base with a join kit, adventure mode, stages with goal boxes, respawn at the current stage, progress saved to `progress.yml`, frozen time and weather, and a `/game` admin command.

### Changes

- **`server_setup mode=game`** sets survival, normal difficulty and forced game mode, so combat, damage and hunger can be tested. `mode=build` (creative, peaceful) stays the default for new servers.
- **Resource pack after `server_detach`**: the pack settings are written to `server.properties`, so a server restarted outside MSC still sends the pack. The pack is also sent again after a restart within a session.
- Many playtest fixes: unknown block names suggest close matches, ground level ignores builds, command syntax errors are reported, and `msc_status` shows the build stamp.

### Install

Download `msc-core-0.2.0.zip`, unzip it and point Claude Code at it as described on the wiki's Installation page. Java 25 must be on the PATH. Paper and Fabric servers still need you to accept the Minecraft EULA yourself.
