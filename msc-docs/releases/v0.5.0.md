## Highlights

Four more platforms, fewer tokens per task, and Windows fixes.

### New platforms

- **NeoForge, Forge, Quilt and Purpur**: `server_setup` installs each server with its own installer, and new **`neoforge-mod`** and **`forge-mod`** templates join the list. Fabric templates also load on Quilt. NeoForge and Forge get their own agents (`msc-agent-neoforge`, `msc-agent-forge`), built on shared vanilla code with the Fabric agent. The first NeoForge or Forge build is warmed up after scaffolding, and Forge's log noise is filtered out.

### Fewer tokens and turns

- **`world_slice`** writes repeated rows and layers once, and a block that occurs once shows its position in the legend. The find-block slice dropped from about 9,000 to 1,900 characters.
- **`world_summary`** lists where rare blocks are (3 or fewer), so finding one block takes one call.
- **`server_command`** runs several commands, one per line, in one call.
- **`texture`** can write a plain `.png` file to a path.
- Bench targets are now set from the first full benchmark run: with MSC, the median task was 35% faster and 45% cheaper than without it.

### Test player

- **`player_test walk x,y,z`** follows the route that `world_summary path` finds.
- The test player stops moving when the server teleports it, and it keeps the game's mode.

### Fixes

- **Windows paths with spaces**: `dev_cycle` works in folders such as `D:\Projects\My Server`, and so does Quilt's `server_setup`.

### Install

Download `msc-core-0.5.0.zip` (it now includes the NeoForge and Forge agents) and follow the wiki's Installation page, or install the plugin. Java 25 must be on the PATH.
