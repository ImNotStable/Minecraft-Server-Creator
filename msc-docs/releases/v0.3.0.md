## Highlights

All three platforms can now be play-tested, the tool list is smaller, and MSC installs as a Claude Code plugin.

### Platforms and play-testing

- **`player_test` on Minestom and Fabric**: the test player joins 26.2 servers such as Minestom, answers Fabric API's configuration ping, and fails clearly when it is kicked. Dev servers turn the whitelist off.
- **`minestom-game` and `fabric-game` templates**: the same minigame base as `paper-game` (join kit, stages with goal boxes, respawn at the current stage, saved progress, `/game` admin command) for Minestom and Fabric.
- **Fabric fixes** from dogfooding, and a shorter `msc_status` when Fabric indexes many API jars.

### Seeing the world

- **`world_render` shows entities, holograms and signs**: entities are dots coloured by kind, text displays and named armor stands show their words, and signs show their text (agents now report sign text in `world.read`). Markers behind blocks are drawn faded and listed, and isometric views label their corners.

### Smaller tool list

- **One build tool**: `build_batch` replaces `build_fill`, `build_set`, `build_structure`, `build_copy` and `structure_load` (new `copy` step), and `msc_stats` is now `msc_status stats=true`. 36 tools became 30, and the tool list costs about 15% fewer tokens in every conversation.

### Install and EULA

- **Claude Code plugin**: the `msc` plugin starts the newest installed core, so a new install needs no `claude mcp add` and no restart; `/mcp` reconnect picks it up. `installMsc` writes a versioned folder per run, and keeps an older flat install working on the newest core.
- **EULA opt-in**: nothing accepts the Minecraft EULA by default. You can opt in once per machine with `installMsc -Pmsc.acceptEula=true`, or by saying yes when the AI asks (`acceptEula=true`). [TERMS.md](https://github.com/ImNotStable/Minecraft-Server-Creator/blob/main/TERMS.md) says what that confirms.

### Build

- **CI on Windows** as well as Linux, which caught and fixed a pack-host port problem on Windows.

### Install

Download `msc-core-0.3.0.zip` and follow the wiki's Installation page, or install the plugin. Java 25 must be on the PATH.
