## Highlights

New platforms and safety nets, on top of a release of fixes. Folia and a Velocity proxy join the platforms, Bedrock players can join through Geyser, every AI build can be rolled back to a whole-world backup, a crashed server explains itself, and the core-to-agent link proves both sides hold the token. Before that, for two days, audits went through every module and every platform (the perfection campaign, [ADR 0029](../docs/adr/0029-perfection-campaign.md)). Each defect they found and confirmed was filed and fixed with a test: more than 300 fixes, all seven platforms checked on real servers twice, and several tools that are much faster.

### New

- **Folia and Velocity** ([ADR 0045](../docs/adr/0045-folia-and-proxies.md)): `server_setup platform=folia` runs Folia with the Paper agent (server operations only; world tools say so), and `platform=velocity` sets up a pinned Velocity proxy with modern forwarding to a backend at 127.0.0.1:25565. A Paper, Purpur or Folia backend joins it with `server_setup proxy=velocity`. New `velocity-plugin` template. BungeeCord and Waterfall are not supported.
- **Bedrock players through Geyser** ([ADR 0046](../docs/adr/0046-bedrock-players-through-geyser.md)): `server_setup bedrock=true` on Paper and Purpur installs the newest Geyser and Floodgate (checksummed) and writes Geyser's config once, on the first free UDP port from 19132.
- **World backups and rollback** ([ADR 0041](../docs/adr/0041-world-backups.md)): `build_undo backup=` lists, saves and restores whole-world backups (newest 5, within 2 GiB). A build of 100,000 blocks or more takes one first.
- **Crash triage** ([ADR 0040](../docs/adr/0040-crash-triage.md)): `server_logs mode=triage` names what died, the culprit, the root cause and a one-line fix from the log, crash report and JVM error file. `server_start` and `dev_cycle` show it first when the server exits.
- **Block entity data** ([ADR 0042](../docs/adr/0042-block-entity-data.md)): chests, signs and other block entities keep their data through `build_batch` (`chest{Items:[...]}`), `world_slice data=true`, `copy`, `structure_save` and `.schem`, on all seven platforms.
- **Safer agent link** ([ADR 0043](../docs/adr/0043-agent-link-auth.md), [ADR 0050](../docs/adr/0050-agent-belongs-to-its-workspace.md)): the token never crosses the wire; core and agent each prove they hold it. A server only attaches to the core of its own workspace.
- **Undo out of order** ([ADR 0049](../docs/adr/0049-undo-out-of-order.md)): `build_undo edit=` undoes any edit that no later edit overlaps, and names the edits to undo first when one does.
- **`./gradlew checkUpstreamVersions`** ([ADR 0039](../docs/adr/0039-upstream-version-check.md)) lists each pinned Minecraft, loader and Minestom version beside the newest stable upstream one.

### Same behaviour on every platform

- **All platforms**: `build_batch` is placed whole or not at all again, also when a write times out, so every changed block stays undoable. `build_undo` now restores sign text and chest contents on all seven platforms, not only Minestom, and it finishes even after a part was evicted. Entities on the boundary between two read pieces are counted once.
- **Paper and Purpur**: a dimension id (`minecraft:the_nether`) works as a world name, as on the mod loaders. A block id with a repeated word gets its "did you mean" hint again.
- **Fabric, Quilt, NeoForge and Forge**: tools no longer time out on an empty server once vanilla pauses it. Text displays (holograms) report their text as the entity name. Text after a block id (`stone[...]extra`) is refused instead of placing the wrong block. A clean start no longer reports harmless loader noise as errors or warnings, on Windows too, and stack traces fold loader frames. Forge mod jars ship `pack.mcmeta`.
- **Minestom**: `server_command` runs console-only commands and reports a failed command. A bad block name says what is wrong and suggests a fix. Reads unload the chunks they loaded, without dropping blocks another read or a player changed. Warnings and stack traces in the log are recognised. `player_test tp` moves the player, and chat reads as text, not as a translation key.
- **Core**: parallel tool calls can no longer deadlock. When the session ends, the core stops promptly and takes down the Gradle builds, installers and pack host it started. One malformed request no longer silences the MCP server. `server_setup` writes the dev defaults even when `run/` already has files. `dev_cycle` never deploys a project over MSC's own agent jar, and `parkour` and `parkour-2` deploy to different files. `api_search kind=event` works on every platform. A released core reports its real version in `msc_status`.

### World tools

- **`build_batch line w=4`** is 4 blocks across (even widths were one short), and a wide line is as fast as a fill of the same box.
- **`replace=`** works on `set`, `structure` and `copy` steps, and matches a partial state such as `oak_stairs[half=top]`.
- **Huge inputs** give a tool error instead of a hang or running out of memory: coordinates near the int limit, very long text rows, and a small `.schem` that claims huge lists. `structure_save` refuses a region longer than 65,535 blocks on a side instead of writing a file that loads smaller.
- **`world_render`**: a first-person camera placed exactly on a block face sees that block, sign markers are hidden only by the blocks really in front of them, textures added to the pack show up without a restart, the caption lists only the markers drawn, and old renders are cleaned up.
- **Walking**: `player_test walk` plans and moves with the same block table, so torches, rails, candles and mangrove roots no longer strand the player on a route the planner found.

### Test player

- Follows the server to other worlds and instances, on Paper and Minestom alike, and keeps walking after a teleport.
- Respawns after every death, including a `/kill` in the nether, and plays on after the end credits.
- Survives a server re-configuration, long falls no longer drop it through the floor, and `goto` and `walk` keep to their own timeout.
- Inventory stays right while a menu is open (smithing and loom included), titles keep their subtitle, the pack check follows HTTP redirects, and events no longer pile up between calls.

### Renderer colours

- Every Minecraft 26.3 block gets its colour from the table or a naming rule: the poplar, sulfur and cinnabar families, wall torches, wall heads and fans, candle cakes and copper ages no longer get made-up colours. A white bed is white, stripped bamboo is not green, and sea lanterns, jack o'lanterns and mangrove roots are full cubes.

### Textures

- `texture_view` works on textures with many colours or many alpha levels, and fast. Pack lint accepts textures wider than 512 px and reports malformed models instead of failing. Textures with the same name in different folders no longer overwrite each other. Ramps go darkest first for every colour.

### Templates

- Project names that would scaffold a project that cannot compile or load are refused, including names whose mod id a loader or MSC's own agent already uses. Names with full-width letters, ligatures or superscript digits get their ASCII form instead of being refused.
- `minestom-game`: `/game <sub> <player>` needs the exact player name. Game progress saves no longer lose the newest snapshot. The `neoforge-mod` and `forge-mod` CLAUDE.md files read correctly again.

### Bench runner

- Attempts run outside the repository (in `~/.msc/bench-runs`), so the "Claude Code alone" baseline really is alone.
- Ctrl-C stops the agent, the core and the Paper server. Timed-out, crashed or never-started attempts are left out of medians instead of counting as zero. Checks reconnect after the agent restarts the server.
- The EULA is read only from the machine's own acceptance (no config file accepts it). Sky Sprint's test player finishes the course again, texture tasks point at the one-call tools, and tasks without a server get no server lines in the prompt.

### Faster

- **Large world reads and writes**: one full-size region (128 x 64 x 128) round trip between core and agent went from about 600 ms to under 200 ms (median), with the same wire format. Every `world_render`, `world_summary`, `build_batch` and test-player read of a big area pays this per piece.
- **Wide `build_batch` lines**: a 64-wide line 2,048 blocks long went from about 15 s to under 1 s.
- **`texture_view`** of a 64x64 texture with many colours went from 66 s to about 50 ms.
- **`replace=` on a repeated step** reads the world once instead of once per copy (`repeat=1024` made 1,024 reads).
- **`world_render` captions** are up to about 25,000 characters shorter, and pack textures are read without reopening the zip for each lookup.

### Changed behaviour to know about

- **Paths**: every tool path must lie inside the workspace (only `msc_workspace` takes an outside path), so `dev_cycle` and `project_scaffold` refuse a project folder elsewhere.
- **Arguments are checked in one place**: every tool call is validated by MSC itself, so a missing, mistyped, unknown or out-of-range argument gets MSC's one-line error that says what to do, and the call shows in the tool log and `msc_status` stats. An argument the tool does not take is now refused (the error lists the ones it takes). Numbers and booleans given as strings (`"5"`, `"true"`) still work.
- **Limits are refused, not clamped**: a `limit`, `timeoutSeconds`, `maxChars`, `lines` or texture `frames` outside its range gets a one-line error instead of a silently changed value. The ranges in the tool reference are generated from the same declaration the check uses.
- **Arguments a call does not use are refused**: `texture` and `pack` refuse an argument the chosen way or kind does not read (`palette` with `kind`, `seed` with a shape, `accent` with a kind that has one colour, `size` with a shape), and `animate` takes exactly `scroll`, `scroll dx,dy` or `pulse`. A scroll's default frame count is one true full loop, and a step that moves nothing is refused.
- **`server_wait`** no longer misses a line the server printed just before it exited.
- **Structure files**: `structure_save` takes a file name ending in `.schem`; `world_summary diff=` and `build_batch file=` recognise a schematic by its content, whatever its name.
- **One result size rule**: every tool result fits `maxChars` (default 6,000). Long results keep their fixed lines and closing line, show as many whole outputs as fit, and say how many were cut.
- **Refusals change nothing**: `server_start`, `server_stop`, `dev_cycle` and `server_setup` check first and refuse before any side effect.
- **One server, one session**: a server belongs to the MSC session that started it while that session lives ([ADR 0037](../docs/adr/0037-server-belongs-to-its-live-core.md)). A second session on the same workspace is refused with the other session's pid instead of stopping its server; a server left by a session that ended is still cleaned up.
- **Server start**: the server's Java is started with UTF-8 console flags, so names and chat in other scripts read correctly under any locale. A workspace path the locale cannot represent gets one clear line.
- **Downloads** fail after 30 s without data instead of hanging, and Purpur downloads are checked against their md5.
- **Resource pack host**: players download the pack in parallel, and a stalled client no longer blocks the others.
- **Switching a server folder between platforms**: a `server.jar` is kept only when MSC recorded it for the platform being set up and its SHA-256 still matches; anything else is removed, and the `server_setup` or `dev_cycle` reply says so with the next step. So a folder switched from NeoForge to Minestom or Fabric and back starts the right jar. After upgrading, an existing NeoForge or Quilt folder installs once more, a Minestom folder needs one `dev_cycle`, and Fabric downloads its vanilla jar again when its setup is rerun.
- **Bench**: `task.json` and `bench.json` are read strictly at every depth (a misspelt key is an error), results are appended safely on a full disk, answer files with a byte-order mark or Windows line ends are read correctly, a task can declare files to reset before its checks, and the exit codes are 0, 1, 2, 3, 4, 5 and 70 as listed in the bench README. `run` refuses a `paths` entry that is not built before any agent starts, and a failed attempt's terminal line gives the same one-line reason as the report.
- **Game templates**: each game template's CLAUDE.md says how to change a rule (time, kit amount, world limits, stage names), and the template's tests prove those steps on the shipped code.

### For developers

- Protocol version 2: the handshake changed ([ADR 0043](../docs/adr/0043-agent-link-auth.md)), so a 0.5 agent and a 0.6 core refuse each other with `version_mismatch`. Run `server_setup` once in each existing server folder to replace the agent jar. `Response.result` is now raw JSON text instead of a `JsonElement` tree ([ADR 0030](../docs/adr/0030-protocol-result-encoding.md)).
- `msc-agent-common` holds the one job queue and tick budget that every agent uses. The previous-protocol client setup lives in one convention plugin, `msc.previous-protocol`. msc-core's texture code uses `msc-textures` instead of a copy, and core's three download routines are one.
- The test suite is faster and steadier: the slowest protocol and bench tests dropped from 58 s to 13 s, 60 s to near zero and 5.5 s to 0.7 s, timing-based tests were rewritten to assert on state, and new tests run 50 times under CPU load before they merge.
- New checks keep the docs honest: the tool reference is generated and checked, and a test fails when a doc names a command MSC does not have.
- Builds: netty gets a version floor like Jackson, labels on a PR no longer cancel its CI run, and Dependabot groups cover all seven platforms.

### Install

Download `msc-core-0.6.0.zip` and follow the wiki's Installation page, or install the plugin. Java 25 must be on the PATH.
