# Minecraft Server Creator

Minecraft Server Creator (MSC) is a set of tools that helps an AI, such as Claude Code, build custom Minecraft servers. You talk to the AI. The AI uses MSC to create the project, run the server, read the logs, build in the world, look at the world and make textures.

It works with **Paper**, **Fabric** and **Minestom**.

## What the AI can do with it

- Create a ready-to-build plugin, mod or server project.
- Download, start and stop a dev server.
- Build, deploy and restart in one step, and see only the errors that matter.
- Look up the Paper, Fabric or Minestom API without guessing.
- Build in the world: fill, set blocks, paste structures, copy, undo.
- See the world as text grids, height maps and rendered pictures.
- Draw pixel-art textures and put them in a resource pack.

## One thing only you can do

Paper and Fabric servers need you to accept the [Minecraft EULA](https://aka.ms/MinecraftEULA). MSC never accepts it for you, and the AI should not either. Read it, and if you agree, tell the AI so (see [Quick start](Quick-start), steps 2 and 3).
