# msc-templates

Starter server projects per platform, ready for the AI to build on, with tests and conventions wired in.

**Phase:** MVP  
**Status:** Planning. No code yet.

## Scope

- A Paper plugin template: Gradle KTS, MockBukkit tests, `CLAUDE.md` conventions.
- Dev server config defaults: EULA, offline mode, fast startup, RCON on.
- Later: Fabric and Minestom templates.

## Depends on

- Conventions from `msc-docs`.

## Stack

Java 21, Gradle Kotlin DSL.
