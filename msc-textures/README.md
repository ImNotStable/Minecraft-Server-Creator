# msc-textures

Advanced texture and model generation beyond the MVP's palette-grid textures.

**Phase:** Post-MVP  
**Status:** Planning. No code yet.

## Scope

- Optional image-model integration for larger art.
- Block and item models, animated textures.
- Consistency checks across a whole resource pack.

## Depends on

- `msc-core`
- An image model, if chosen.

## Stack

Java 25, Gradle Kotlin DSL.
