# msc-agent-minestom

A Minestom extension or library hook that speaks `msc-protocol`, giving Minestom servers the same world and server tools.

**Phase:** Post-MVP  
**Status:** Planning. No code yet.

## Scope

- Protocol client and command execution.
- Block edits and region reads on Minestom instances.
- Template covers world loading and basic block handling, since Minestom has no vanilla logic.

## Depends on

- `msc-protocol`
- Minestom.

## Stack

Java 25, Gradle Kotlin DSL.
