# msc-agent-fabric

A server-side Fabric mod that speaks `msc-protocol`, giving Fabric servers the same world and server tools as Paper.

**Phase:** Post-MVP  
**Status:** Planning. No code yet.

## Scope

- Protocol client and command execution.
- Block edits and region reads through Fabric and Minecraft internals.
- Fabric API index built from mappings.

## Depends on

- `msc-protocol`
- Fabric Loader and Fabric API.

## Stack

Java 21, Gradle Kotlin DSL.
