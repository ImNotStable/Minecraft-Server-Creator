# msc-bench

Benchmark tasks and a runner that measure whether the toolset makes AI server development better on quality, speed and tokens.

**Phase:** MVP  
**Status:** Planning. No code yet.

## Scope

- A set of 5 to 10 MVP tasks covering code, building, world views and textures.
- A runner that does each task with and without the toolset.
- A report of pass rate, time, turns and tokens per task.

## Depends on

- `msc-core` for token and timing logs.

## Stack

Java 21, Gradle Kotlin DSL.
